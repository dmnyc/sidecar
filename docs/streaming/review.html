This uses Sidecar’s actual sidebar markup, theme, toolbar, navigation, and lock screen, with fictional account data.

How you reach it

Select the radio-tower icon in the toolbar. Choose a stream to watch. The square Stop icon ends playback and removes the player; the toolbar entry remains available.

What happens to navigation

The player stays pinned above the existing toolbar and four tabs. Try Accounts, Activity, Profile, and Wallet while watching. Only the content area below them scrolls.

The expand icon gives the player more height. Signing temporarily makes it compact so the approval controls have room.

Try the other states

No real accounts, keys, or payments are connected. Livestreams are real public streams.

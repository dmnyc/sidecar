Relay drafts lab

NIP-37 drafts on a private relay that requires NIP-42. Do the steps in order, in the side panel. The ticks under “The relay saw” come from the relay itself; the ones under “You judge” are yours to click.

Relay: looking…
The relay is not running. Start it from the repo root: node test/manual/nip42-relay.js

Steps

  1. Make the relay the account’s only one. In Sidecar, the gear → Settings → Relays (not the Profile tab’s list): remove every relay, then add the address above (a warning about ws:// is expected; it is your own machine). Then reload the panel.
  2. Start a draft. Open the composer, type a note that starts with LAB- (so the page can tell if its words ever reach the relay as plaintext), and don’t post it.
  3. Save it to relays. Saved drafts → the cloud button on “Open now”. With no relay list it should say so and offer to publish one naming the relay: press it, then set up private relays, and the draft is saved.
  4. A draft from another client. (two cards: Allow both). Then in Saved drafts press Check your relays: the draft should be listed. Open it: the note in progress should be set aside first, not overwritten.
  5. Delete it from your relays (trash on that relay draft, tap twice). The relay’s copy should be blanked.
  6. Post the first draft (it publishes a real note to this account’s relays: use the throwaway). Its relay copy should be blanked too.
